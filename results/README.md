# Results

Everything here is generated by the code in `../src`. The folders under `runs/` mirror the folders under `src/`.

| Folder | Contents |
|---|---|
| `runs/sweep/` | The parameter sweep: job files (`jobs/`), one result file per batch (`done/`), and the pilot batch |
| `runs/tvb_reference/` | One record per run in The Virtual Brain, at four integration steps |
| `runs/validation/` | The JAX-against-TVB checks, and the two small arrays described below |
| `runs/earlier_studies/` | Output of the work that came before the sweep, by study |
| `figures/report/` | The figures of the write-up (`../doc/sweep_writeup.pdf`) |
| `figures/maps/` | The summary statistics over (G, σ), and how closely each parameter's effect lines up with G's |
| `figures/derivatives/` | One map per parameter: how each statistic changes with it |
| `tables/` | Peak locations and summary numbers behind the maps |

Each record is a JSON file of summary statistics for one run or one batch. Run logs sit in a `logs/` folder beside
the records they belong to.

The raw simulation arrays (`*.npz`, about 1.5 GB) are not in the repository. Two small ones are:
`runs/validation/tvb_ref_dump.npz` (TVB's own buffers, for the step-by-step check) and
`runs/validation/traces_wp.npz` (per-volume traces for one figure).
