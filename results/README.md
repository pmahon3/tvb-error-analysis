# Results

Everything here is generated by the code in `../src`.

| Folder | Contents |
|---|---|
| `runs/` | One JSON record of summary statistics per simulation run, plus run logs. `runs/sweep/` is the sweep of 2026-11-24, `runs/Aprime/` the TVB reference runs, `runs/port/` the JAX-against-TVB checks (the folder keeps its old name). Older files at the top level belong to the earlier reimplementation. |
| `figures/report/` | The five figures of the write-up (`../doc/sweep_writeup.pdf`) |
| `figures/maps/` | The summary statistics over (G, σ), and how closely each parameter's effect lines up with G's |
| `figures/derivatives/` | One map per parameter: how each statistic changes with it |
| `tables/` | Peak locations and summary numbers behind the maps |

The raw simulation arrays (`*.npz`, about 1.5 GB) are not in the repository. Two small ones are: `runs/port/tvb_ref_dump.npz`
(TVB's own buffers, for the step-by-step check) and `runs/port/traces_wp.npz` (per-volume traces for one figure).
