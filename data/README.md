# Input data

Read-only inputs. Nothing here is generated by this project's code except as noted.

| File | What it is |
|---|---|
| `weights.txt`, `tract_lengths.txt` | The public 76-region connectome distributed with The Virtual Brain (default connectivity). Used by the earlier reimplementation (`src/common/mpr_net.py`). The exact upstream file version was not recorded. |
| `hcp001_conn.npz` | Weights and tract lengths of the 84-region connectome in `../external/pci_fluidity/hcp-001.zip`, as The Virtual Brain configures them through the companion code (weights divided by their maximum). The same two arrays that `src/5_tvb_reference/tvb_ref_dump.py` saves into `results/runs/port/tvb_ref_dump.npz` (checked equal). Read by the JAX version. |

Third-party code, and the data files that code reads directly, are in `../external/`.
